An interactive minimap, full map, compass and collection tracker for Wuchang: Fallen Feathers. Built @@DATE@@.

This is a beta

The Chapter 1 map, the markers, the minimap, the full map and the collection tracker have been tested in-game. The Chapter 2–5 maps and the x-ray highlight have not yet been verified in-game — they are built from the same pipeline and should work, but expect rough edges. The DLC has no map at all: the game ships no navigation data for it (markers still work).

1. Prerequisites

The mod is a UE4SS C++ mod. You need UE4SS installed for Wuchang first — use the build packaged for this game, UE4SS for Wuchang: Fallen Feathers, Nexus Mods mod 384 for Wuchang. Install it into the game's binaries folder:

<Steam>\steamapps\common\Wuchang Fallen Feathers\Project_Plague\Binaries\Win64\

After that folder contains dwmapi.dll (UE4SS's loader — the game loads it at start-up) and a ue4ss\ subfolder, UE4SS is installed.

Mandatory: HookInitGameState = 0

Open Project_Plague\Binaries\Win64\ue4ss\UE4SS-settings.ini, find the [Hooks] section, and set:

[Hooks]
HookInitGameState = 0

Without this the game crashes about a third of a second into loading, with or without this mod — UE4SS's hook on AGameModeBase::InitGameState breaks Wuchang's custom game mode and a blueprint then reads a null game state. Every other hook can stay on. This is a UE4SS-plus-Wuchang problem, not a bug in this mod.

2. Install

  1. Make sure the game is closed.
  2. Open the folder this guide is in. It contains a single ue4ss\ folder.
  3. Copy that ue4ss\ folder into 
    <Steam>\steamapps\common\Wuchang Fallen Feathers\Project_Plague\Binaries\Win64\
    and merge when Windows asks. Nothing of UE4SS's own is overwritten — everything in the package lives under ue4ss\Mods\WuchangMinimap\.
  4. Check [Hooks] HookInitGameState = 0 as described above.
  5. Launch the game. Load a save (the mod deliberately shows nothing on the main menu), then press F2.

The installed layout, for reference:

Project_Plague\Binaries\Win64\
  dwmapi.dll                     <- UE4SS's loader (from UE4SS, not from this package)
  ue4ss\
    UE4SS-settings.ini           <- must have [Hooks] HookInitGameState = 0
    Mods\
      WuchangMinimap\
        dlls\main.dll            <- the mod
        maps\                    <- the map assets, one folder per chapter
        markers\                 <- the marker database, one file per chapter
        config_wuchang_minimap.txt   <- all overlay settings
        config.ini                   <- the developer navmesh dumper (off)
        enabled.txt              <- empty; this is what tells UE4SS to load the mod

There is no mods.txt to edit: the empty enabled.txt is the opt-in.

3. Hotkeys

Anywhere in the game

F5Reload the config file, the map assets and the marker database
LALT held X-ray highlight: nearby uncollected chests and pickups are drawn through walls, with name and distance. It is a hold, not a toggle.
LB+RB heldThe same, on a controller

While the full map is open

InputAction
Drag, WASD, arrowsPan
Mouse wheel, + / -Zoom
Ctrl+wheel, Q / E, PgUp / PgDn Move the height slice down / up a floor
RRecentre on the player, clear the floor offset
Left-click a marker, or FToggle "found" by hand (writes the tracker)
Right-click, or SpaceSet the waypoint (it also shows on the minimap and compass)
M or EscClose
GamepadLeft stick pan · triggers or right stick zoom · LB/RB floor · A waypoint · X found · Y recentre · B close

Keys the mod refuses to bind

F6 and F9–F12 are rejected in code: if you put one of them in the config file the mod ignores it and falls back to the default. They belong to other things — F6 toggles RenoDX / DLSS 5 Neural Rendering (which hung the GPU when pressed in-world during development), F10 opens the game console, F12 is the Steam screenshot key, and F9 / F11 are engine screenshot and fullscreen binds. Everything else is fair game: F1–F5, F7, F8, any letter or digit, Tab, Space, and the modifier keys (LALT, LSHIFT, LCTRL, …).

4. Configuration

Everything lives in one plain-text file, ue4ss\Mods\WuchangMinimap\config_wuchang_minimap.txt. Lines are key = value; ; and # start a comment. The file itself documents every key. Edit it and press F5 in-game — no restart needed. The F2 panel edits the same settings and its Save settings button writes them back.

GroupWhat it controls
enabled, show_minimap Master switch (0 installs no graphics hooks at all) and the minimap itself.
minimap_size, minimap_zoom, minimap_shape, minimap_anchor, opacity, rotate_with_player Shape, size, placement and zoom of the minimap. minimap_zoom is world units per pixel — smaller is more zoomed in.
hide_in_menus, require_pawn_view, state_stale_ms, min_visible_after_state_ok_ms When the overlay is allowed on screen. The defaults keep it off the main menu, out of cutscenes and out of loading screens.
floor_z_tolerance, floor_fade_uu, show_adjacent_floors, adjacent_floor_opacity, floor_gradient_strength, floor_base_color Height slicing — how the mod decides which storey you are on and how the ones above and below are dimmed. This is the group worth tuning in a multi-storey temple.
markers_* Which marker categories are drawn, their size, whether found ones are hidden, and the cost dials for the live actor sweep.
map_* The full map: opening zoom and limits, pan speed, margins, gamepad, waypoint persistence.
highlight_* The x-ray highlight: key, radius (default 3000 uu = 30 m), categories, labels, edge arrows.
compass_* The compass strip: width, height, how many degrees it spans, which markers get a pip.
panel_key, map_key, map_recenter_key, reload_key, highlight_key Rebinding. The F2 panel and the full map's footer read the key hints straight out of this file, so they cannot go stale after a rebind.

The second file, config.ini, controls a developer tool only: a runtime navigation-mesh dumper, off by default (navmesh_dump = 0). Leave it alone. It has nothing to do with the maps you see — those were extracted offline from the game's own data.

5. Your files

Two files are yours, written by the mod as you play. They live next to the config, in ue4ss\Mods\WuchangMinimap\, and no install or update ever overwrites them:

FileWhat it is
wuchang_minimap_found.txt The collection tracker: one marker id per line. The mod adds a line when it sees you open a chest or take a pickup, and you can toggle one by hand by clicking it on the full map. Plain text, hand-editable; delete the file to reset your tracking.
wuchang_minimap_waypoint.txt Your waypoint, so it survives a restart. Three key = value lines.

They are tied to a save, not to the game — if you start a new character, delete wuchang_minimap_found.txt.

6. Uninstall

  1. Close the game.
  2. Delete Project_Plague\Binaries\Win64\ue4ss\Mods\WuchangMinimap\.

That is the whole mod — it writes nothing anywhere else, touches no save file and modifies no game data. To keep it installed but switched off, either delete just WuchangMinimap\enabled.txt, or set enabled = 0 in the config. To remove UE4SS as well, delete dwmapi.dll and the ue4ss\ folder.

7. Troubleshooting

Start here: the log

UE4SS writes Project_Plague\Binaries\Win64\ue4ss\UE4SS.log. Search it for WuchangMinimap: the first line reports the version (WuchangMinimap v@@VERSION@@ loaded), and every line the mod writes is prefixed [minimap], [markers] or [navmesh]. That file is the first thing to attach to a bug report.

The game crashes on start-up

Almost always HookInitGameState. Set [Hooks] HookInitGameState = 0 in ue4ss\UE4SS-settings.ini (see section 1). To confirm UE4SS is the cause at all, rename dwmapi.dll temporarily: if the game still crashes, it is not UE4SS and not this mod.

Nothing appears in-game

  • Are you actually in the world? The overlay is deliberately hidden on the main menu, in cutscenes, in menus, and for a moment after a load.
  • Press F2. If the panel opens, the mod is running and the graphics hooks are in; the minimap is just being suppressed.
  • With debug_readout = 1 (the default) the panel prints one line hidden because: <reason> that names the exact condition holding it back — a stale snapshot, no gameplay pawn, an open menu (it even names the widget), the grace period, or the camera not looking through the player. Read that line before anything else; it is there specifically so "the minimap vanished" has an answer.
  • If F2 does nothing either, check enabled.txt exists and look for WuchangMinimap v@@VERSION@@ loaded in UE4SS.log.

A hotkey does nothing

Check it is not one of the rejected keys (F6, F9–F12 — the mod silently falls back to the default), and check the Keys block at the bottom of the F2 panel, which prints the bindings actually in force.

ReShade / RenoDX / DLSS 5 installed

They coexist. The mod draws before ReShade's effects, so a strong preset will tint the overlay — that is cosmetic and expected. One real caution: RenoDX's DLSS 5 add-on binds F6 and ignores modifiers, and toggling it mid-game hung the GPU during development. That is why this mod refuses to bind F6 at all.

The map looks wrong or empty

  • The map is drawn from the game's walkable navigation data, so unreachable geometry (rooftops, cliffs, scenery) is genuinely not on it.
  • Only the storey you are on is drawn solid. In a multi-storey building, raise floor_z_tolerance or adjacent_floor_opacity to see more of it, or open the full map and step the slice with Q / E.
  • In the DLC there is no map at all — the game ships no navigation data for it. Markers still work.
  • The chapter is identified from the levels the game has streamed in, which can take a couple of seconds after a transition. The F2 panel shows the chapter currently in force.

Frame time

The F2 panel's debug block prints scan pump (what one marker-sweep step costs the game thread — keep it under about 1 ms) and round (how long a full pass took). If pumps are expensive, halve markers_scan_chunk; a full pass simply takes proportionally longer. One chapter's map assets need roughly 340 MB of RAM, and only one chapter is ever resident.
