WuchangMinimap v@@VERSION@@

A minimap, full map, compass and collection tracker for Wuchang: Fallen Feathers, with the map built from the game's own navmesh. Built @@DATE@@.

1. Requirements

This is a UE4SS C++ mod. Install UE4SS for Wuchang: Fallen Feathers (Nexus Mods mod 384 for Wuchang) first, into:

<Steam>\steamapps\common\Wuchang Fallen Feathers\Project_Plague\Binaries\Win64\

It must be this exact UE4SS build

UE4SS v3.0.1-1111-g97b7e501   (the "experimental-latest" asset of Nexus mod 384)

The mod links straight to that DLL's exports, so another UE4SS build will not work, and the failure is silent: the game plays normally, no overlay appears, F2 does nothing, and ue4ss\UE4SS.log contains

Failed to load dll <...\Mods\WuchangMinimap\dlls\main.dll> for mod WuchangMinimap,
error: The specified procedure could not be found.

rather than WuchangMinimap v@@VERSION@@ loaded. BUILD_INFO.txt in this folder repeats the version.

Mandatory: HookInitGameState = 0

Open Project_Plague\Binaries\Win64\ue4ss\UE4SS-settings.ini, find the [Hooks] section, and set:

[Hooks]
HookInitGameState = 0

Without this the game crashes about a third of a second into loading, with or without this mod: UE4SS's hook on AGameModeBase::InitGameState breaks Wuchang's custom game mode. Every other hook can stay on. It is a UE4SS-plus-Wuchang problem, not a bug in this mod.

2. Install

  1. Make sure the game is closed.
  2. Copy the ue4ss\ folder from this download into Project_Plague\Binaries\Win64\ and merge when Windows asks. Everything in the package lives under ue4ss\Mods\WuchangMinimap\, so nothing of UE4SS's own is overwritten. Updating over an old install: Windows offers to replace config_wuchang_minimap.txt — keep yours if you have edited it.
  3. Check [Hooks] HookInitGameState = 0, as above.
  4. Launch the game and load a save — the overlay is hidden on the main menu — then press F2.

There is no mods.txt to edit: the empty enabled.txt in the mod folder is the opt-in. To uninstall, delete ue4ss\Mods\WuchangMinimap\. The mod modifies no game or save data.

3. Hotkeys

KeyAction
F2Settings panel — every setting, in Player / Advanced / Bindings tabs
MFull map. Drag or WASD to pan, wheel to zoom, Q/E for the floor, Home to fit, right-click for a waypoint (again on it removes it, up to 16), the search box to show only markers whose name matches, C to copy it to the clipboard, F1 or H for the rest, Esc to close
LALTX-ray highlight: nearby markers drawn through walls with names and distances. A toggle — press again to turn it off
LB+RBThe same, on a controller
Back+YOpen / close the full map on a controller. The map itself takes a gamepad throughout: left stick pans, the triggers zoom, LB/RB change floor, A drops or removes a waypoint, B closes it
NCycle the minimap zoom
RRecentre the full map on the player
GSet a waypoint on the nearest marker you have not found yet, among the categories you have switched on. A toast names it and its distance
F5Reload the config, the map assets and the marker database

Everything is rebindable in the F2 panel's Bindings tab: click a row and press the new key — hold Ctrl, Shift or Alt with it to bind a combination such as Ctrl+M. F6 and F9–F12 are refused — they belong to RenoDX/DLSS, the engine, the game console and Steam. The tab warns when a key is one the game itself is likely to want.

A key bound to the mod is taken away from the game while the mod is using it. Put a modifier in front of the binding to leave the bare key to the game.

Settings live in ue4ss\Mods\WuchangMinimap\config_wuchang_minimap.txt, which documents every key inline; the F2 panel edits the same file, and F5 reloads it without restarting the game.

4. Known conflicts

WhatWhat happens
ReShade / RenoDX
any dxgi.dll or d3d12.dll next to the game exe		 The mod draws before ReShade's effects, so colour-grading, tone-mapping and sharpening are applied on top of the minimap and a strong LUT tints it. Cosmetic only. F6 is refused as a mod hotkey because it is RenoDX's default toggle.
Another UE4SS C++ mod that also hooks Present The one combination that can lose an overlay: two overlays on one swapchain, whichever installs second usually wins, and the loser is invisible. Test them one at a time before reporting a blank screen.
The Steam overlay The first run of a new install creates and destroys a throwaway swapchain, which Steam's overlay follows, so its FPS counter can end up pointing at nothing. The addresses are cached afterwards, so it is the first run only. Shift+Tab keeps working.

5. Something went wrong

The game crashes on start-up — almost always HookInitGameState; see section 1.

Nothing on screen — press F2. If the panel opens, the mod is running and only the minimap is suppressed: the top of the Player tab prints one orange hidden because: line naming the exact reason. Screenshot it.

Reporting a bug: attach this file

ue4ss\Mods\WuchangMinimap\wuchang_minimap.log — the mod's own log, rotated per launch (.1….3 are previous sessions). Its first six lines carry every version number a report needs.

Also useful: wuchang_minimap_last_stage.txt if the game crashed, wuchang_minimap_watchdog.txt if it froze, and your config_wuchang_minimap.txt.

If you are asked to reproduce something, first set log_level = verbose in the config (or pick it under Advanced → Diagnostics → Log detail in the panel — it takes effect at once), then reproduce it and send the log.
