# ajira-mcp — автономный MCP-сервер AgentJira

Один файл на чистой стандартной библиотеке: его копируют в произвольный проект, чтобы агент этого
проекта работал с уже запущенной AgentJira по HTTP. Нужен только Python 3.9+ — ни `pip install`,
ни зависимостей самого трекера.

`ajira_mcp.py` — **сборка**, а не исходник: каталог инструментов и обработчики живут в
`ajira/mcp_core.py`, транспорт — в `scripts/standalone_parts/runtime.py`, а складывает их
`scripts/build_standalone.py`. Править нужно там и пересобирать файл; `pytest` падает, если
собранный файл разошёлся с исходниками.

## 1. Поднять AgentJira

В папке трекера:

```powershell
ЗАПУСТИТЬ.cmd                                  # или: uv sync; uv run python -m ajira serve
```

Трекер слушает `http://127.0.0.1:8787`. Порт занимает он, копия MCP-сервера порт не занимает:
она общается по stdio.

## 2. Выдать агенту токен

Токен показывается один раз — сохраните его сразу в файл, например `tools/ajira/token.txt`:

```powershell
uv run python -m ajira actor-add <проект>-agent --model <модель> --max-parallel 3
```

Забытый токен перевыпускается без нового агента: `ajira actor-rotate-token <id агента>`. Id берётся
из `ajira actors` — команда печатает таблицу с колонкой `ID`.

## 3. Скопировать папку в проект

Положите `ajira_mcp.py`, `README.md` и `mcp.json.example` в любое место проекта, например
`tools/ajira/`. Копировать нужно именно папку: сервер ничего не читает рядом с собой и работает
откуда угодно.

В папке есть ещё скилл `skills/agentjira/SKILL.md` — краткая инструкция для агента проекта. Скопируйте
его в `.claude/skills/agentjira/SKILL.md` проекта-потребителя: Claude Code подхватит скилл, и агент
увидит цикл работы с трекером как правило, а не только через инструкцию на `initialize`.

## 4. Прописать сервер в конфигурации агента

Возьмите `mcp.json.example`, подставьте путь к `ajira_mcp.py`, путь к файлу с токеном и ключ
проекта:

```json
{
  "mcpServers": {
    "ajira": {
      "command": "python",
      "args": ["<путь к папке>/ajira_mcp.py"],
      "env": {
        "AJIRA_URL": "http://127.0.0.1:8787",
        "AJIRA_TOKEN_FILE": "<путь к файлу с токеном>",
        "AJIRA_PROJECT": "DF"
      }
    }
  }
}
```

Токен передаётся **файлом**, а не строкой в `env`: `.mcp.json` обычно коммитят, и секрет уехал бы
в репозиторий. Файл положите рядом с конфигом агента и добавьте его в `.gitignore`.

Настройки читаются из окружения: `AJIRA_URL` (по умолчанию `http://127.0.0.1:8787`),
`AJIRA_TOKEN_FILE` (файл с токеном), `AJIRA_TOKEN` (сам токен; без него сервер работает как
человек из браузера — агенту он нужен), `AJIRA_PROJECT` (ключ проекта: уходит заголовком
`X-Ajira-Project`; без него — проект по умолчанию трекера), `AJIRA_TIMEOUT` (таймаут одного
запроса, по умолчанию 30 с). Те же значения можно передать аргументами: `--url`, `--token`,
`--token-file`, `--project`, `--timeout`.

## 5. Проверить подключение

Агенту достаточно вызвать `me` — он ответит именем, лимитами и остатком бюджета. Без агента
проверяется двумя строками в консоли (сервер отвечает JSON-строками в stdout):

```powershell
'{"jsonrpc":"2.0","id":1,"method":"initialize"}' | python ajira_mcp.py
'{"jsonrpc":"2.0","id":2,"method":"tools/call","params":{"name":"me","arguments":{}}}' | python ajira_mcp.py
```

Первая строка печатает имя сервера и инструкцию: в ней уже названы проект, счётчики готовых задач
и записей Inbox и страницы плана — сервер спрашивает это у трекера при подключении. Вторая —
карточку агента. В stdout сервер пишет только JSON-RPC, поэтому посторонних строк быть не должно.

## Порядок работы агента

`issue_list` (`status=ready`, `label=agent-ready`; `compact=true` — без описаний, чтобы список на
сотню задач не съел контекст) → `issue_claim` (для долгой работы бери `ttl_seconds` больше, до
86400) → `issue_heartbeat` каждые ~1/3 TTL (пропущенный heartbeat — лиз истекает, задача
возвращается в `ready`) → `issue_comment` и `issue_worklog` (от worklog зависят суточные бюджеты) →
`issue_attach` для артефакта → `issue_transition` в `review`. Перед `review` нужен след работы после
старта (комментарий, worklog или вложение), иначе `409`. В `done` агент переводит задачу сам, если у
неё нет метки `needs-human`: такую закрывает человек, и снять её агент не может. Критерии приёмки
видны в `issue_get` — отмечай их `issue_checklist_tick` по мере выполнения; ненужный критерий
закрывает `issue_checklist_waive` с причиной, правит `issue_checklist_edit`, удаляет
`issue_checklist_remove`.

Человека зовут по конкретной задаче через `attention_request`: `kind` различает вопрос (`question`),
утверждение до необратимого шага (`approval`), просьбу о правках по сданной работе (`review`),
блокер (`blocked`) и упоминание (`mention`); ответы читаются через `inbox_list`. Блокер — ещё и
`issue_transition` в `blocked` с причиной в `note`. Если в проекте включён
`require_checklist_done_for_done`, в `done` не пустят, пока не закрыт каждый критерий приёмки
(выполнен или «не требуется»).

Страницы плана читаются через `docs_list` (`compact=true` — только дерево) и `doc_get`, а пишутся
через `doc_create` и `doc_update`. У страницы бывает `source_path` — путь к файлу репозитория:
тогда текст читается из файла, а `doc_update` меняет только заголовок и путь, потому что правда
живёт в git.

## 6. Куда попадают задачи

Проект запроса называет `AJIRA_PROJECT` (или `--project`): он уходит заголовком
`X-Ajira-Project` в каждом запросе, и все инструменты — `issue_list`, `issue_create`, `docs_list`,
`search` — работают с ним. Без переменной запрос идёт в проект по умолчанию трекера: ключ
`[project] key` из `ajira.toml`. Названный проект, которого нет в трекере, — `404`: молча писать
задачи в чужой проект хуже отказа.

**Проблема с самим трекером — задача в трекере.** Если при работе с AgentJira возникает проблема или
затруднение — ошибка, непонятный отказ, неудобный или недостающий инструмент или поле, неясная
инструкция — или видно, что нужен фикс или улучшение, заведи задачу через `issue_create` в проекте
трекера (ключ — `tracker_project` из `GET /api/v1/meta`, его же называет инструкция на
`initialize`). Не обходи молча и не откладывай: опиши, что делал, что получил и что ожидал.

Правило для агента: **вопрос человеку, снятие блокера и правки по сданной работе идут через
`attention_request`, а не задачей.** Задача в проекте трекера — для проблем и доработки самого
трекера (выше). Рабочие задачи проекта заводятся в проекте проекта. Это же правило сервер называет в инструкции на `initialize`, поэтому агент видит его при
подключении, а не только здесь.

## Если что-то не работает

| Что видно | Причина и что делать |
|---|---|
| `401 нужен токен агента` / `токен не найден` | `AJIRA_TOKEN` не задан, указан с опечаткой или отозван. Проверьте `ajira actor-add` и знайте: токен показывается один раз |
| `файл с токеном не найден` / `файл с токеном пуст` | `AJIRA_TOKEN_FILE` указывает не туда. Путь читает процесс агента, а не трекер |
| `404 проект NOPE не найден` | `AJIRA_PROJECT` называет проект, которого в трекере нет. Посмотрите `GET /api/v1/projects` или уберите переменную |
| Задача ушла не в тот проект | `AJIRA_PROJECT` не задан, и запрос ушёл в проект по умолчанию трекера. Задайте `AJIRA_PROJECT` и пересоздайте задачу там, где нужно, а лишнюю попросите удалить человека: переноса задач между проектами в API нет, `DELETE` доступен только человеку |
| `403 действие запрещено` | Действие доступно только человеку: закрыть задачу с меткой `needs-human`, удалить задачу, переименовать проект, перенести историю |
| `409` (`already_claimed`, версия не совпала, гвард перехода) | Задачу держит другой агент — возьмите другую; либо перечитайте `issue_get` и повторите: текст отказа объясняет причину словами сервера |
| `429` (`limit_exceeded`) | Исчерпан потолок параллельных задач или суточный бюджет. Освободите лишние задачи через `issue_release` / `me` и дождитесь следующих суток UTC |
| `сервер http://... недоступен` | AgentJira не запущена или `AJIRA_URL` указывает не туда. Обратите внимание на схему: `http://127.0.0.1:8787`, а не `127.0.0.1:8787` |
| `сервер ... не ответил за 30 с` | Трекер занят или завис: поднимите `AJIRA_TIMEOUT`, проверьте процесс трекера |
| `413 файл больше допустимого размера` | Вложение больше лимита (по умолчанию 50 МБ): приложите выжимку или ссылку в `meta` |
| Агент не видит инструментов | Проверьте путь в `args` и что запускается Python 3.9+. Диагностика сервера идёт в stderr, а не в stdout |
